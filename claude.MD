## Agent Notes

### Code Standards

-   **Clean Code**: Follow principles of Clean Code by Robert C. Martin
-   **Self-Documenting**: Use clear names. Comment WHY and not WHAT
-   **Prefer UK English**: UK spelling over US spelling.

- When dealing with large numbers over 1000, use numeric separators with underscores, e.g. 1_000_000 


### Architecture Principles

-   **Avoid early abstractions**: Start simple, add complexity only when needed
-   **SOLID principles**: Ensure that generated code follows the principles of single responsibility, open–closed, liskov substitution, interface segregation, and dependency inversion.
